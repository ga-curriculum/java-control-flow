The solution to the independent practice exercise in the conditional operators microlesson is:

```java
int speed = 80;
int speedLimit = 60;
String status = (speed > speedLimit) ? "Over Speeding" : "Within Limit";
System.out.println(status); // Output: Over Speeding
```
